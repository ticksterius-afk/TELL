# TELL — decisions made during the build session

Choices the spec left open, or where the spec contradicted itself, with the reason.
The "Decisions already made" in [SPEC.md](SPEC.md) §9 were not reopened.

## M0 — engine spine

- **Blink mapping window is smoothstep(1.0, 2.0), not (1.0, 2.5).** SPEC §4.2 asks for
  `smoothstep(1.0, 2.5)` of `longestOpen(S) / max(longestOpenBase, 1.5 × IBI median)`,
  and §8 test (b) asks that 8 s without a blink against a 3 s baseline IBI gives
  blink ≥ 0.8. With a regular 3 s blinker the reference is 4.5 s, the ratio is 1.78 and
  smoothstep(1.0, 2.5) gives 0.53. The test is the behavioural requirement, so the upper
  edge is 2.0 ("eyes held open twice as long as usual is a full tell"). `tell.json.blink`
  holds both edges; M4 re-tunes them on real sessions.
- **Baseline grows by leave-one-out.** `tell.json.baseline.grow` is `true`: statement *i*
  is compared with the baseline plus the other statements. The reference becomes "how
  this person talks in this session" (24–40 s instead of 12 s), which makes P90 and the
  longest-open stretch robust; a stare in statement 2 does not make statements 1 and 3
  look suspicious.
- **Component names avoid emotion words.** The spec's table names one component
  "Surprise brows"; §7 forbids emotion labels in scores and captions, so it is shown as
  "Raised brows". The component ids (`blink`, `leak12`, `brows`, `asym`, `micro`,
  `freeze`) are as specified.
- **Recorded frames carry a quality value.** `RecordedFrame` has `quality` (0–1) and
  `qualityReason` ("size" | "light" | "pose") in addition to the fields in §4.1, because
  the quality gate in §4.2 needs the per-frame estimate and the reason for the
  "unscored" text. Replayed fixtures have no pixels, so their quality is the head-pose
  factor only.
- **Default AU set adds the per-side channels** AU2L/R, AU12L/R, AU14L/R so a one-sided
  caption can name the side ("Left lip corner pulled at 4.1 s", the subject's left).
- **Luminance comes from the forehead crop** the texture path already reads (≤ 200 px
  wide), not a full-face crop; it is the only pixel read-back in the app and is enough
  for the "Move to the light" hint.
- **Fixture marker for the false statement is `false:N`**, not `lie:N` as the spec's
  example shows, so the word never appears in source or data. Markers: `calibrate:3`,
  `baseline`, `statement:N`, `feed`, `end`, `false:N`.
- **A synthetic ARKit fixture pins the scorer** (`model/fixtures/tell/synthetic-arkit.json`,
  generated by `npm run fixture:tell`) until real recordings exist. It is not tuning data.
- **Poker Face scale**: leakage is the time integral of the excess (AU·s);
  `pokerface.scale = 8` AU·s empties the score (for example 16 s of a half-intensity
  smile). Bin levels 0.12 / 0.5 / 1.2 AU·s. Placeholders for M4.
- **Developer recorder saves via the share sheet** when the browser can share files
  (iOS Safari, Android Chrome), otherwise as a download. File name
  `tell-YYYY-MM-DD-HHMM.json`; the current calibration and range gains are embedded so
  the replay reproduces the engine state.
